# 第三方系统调用模版

> 适用于对接本项目后端 API（默认 `http://127.0.0.1:5000`）

## 1. 接入基础信息

- Base URL: `http://127.0.0.1:5000`
- 内容类型: `application/json`（`/api/upload` 和 `/api/generate-grid` 例外，使用 `multipart/form-data`）
- 鉴权: 当前项目默认未启用鉴权（建议生产环境加 API Gateway 或 Token 校验）
- 跨域: 后端默认放开 CORS（开发友好）

---

## 2. 响应约定

### 成功响应（示例）

```json
{
  "success": true,
  "message": "Task queued",
  "task_id": "xxx",
  "status": "queued"
}
```

### 失败响应（示例）

```json
{
  "success": false,
  "error": "Missing required field: images_dir",
  "message": "Missing required field: images_dir",
  "error_code": "ERR_MISSING_FIELD"
}
```

---

## 3. 两类调用模式

1. 同步接口（直接返回结果）  
如：`/api/scan-voc-classes`、`/api/scan-yolo-classes`、`/api/remove-duplicates`（当前实现是同步）

2. 异步任务接口（返回 `task_id`）  
如：`/api/split`、`/api/match`、`/api/convert`、`/api/crop`、`/api/generate`、`/api/augment`、`/api/clean-dataset`、`/api/find-duplicates`、`/api/modify-labels`、`/api/visualize`

异步任务通用流程：

1. `POST /api/xxx` 拿到 `task_id`
2. 轮询 `GET /api/progress/{task_id}` 或订阅 `GET /api/task/{task_id}/stream`
3. 任务终态：`completed | error | stopped | cancelled`

---

## 4. cURL 调用样例

### 4.1 同步接口样例（扫描 VOC 类别）

```bash
curl -X POST "http://127.0.0.1:5000/api/scan-voc-classes" \
  -H "Content-Type: application/json" \
  -d '{
    "annotations_dir": "/path/to/annotations"
  }'
```

### 4.2 异步接口样例（数据集划分）

```bash
# 1) 创建任务
curl -X POST "http://127.0.0.1:5000/api/split" \
  -H "Content-Type: application/json" \
  -d '{
    "format": "voc",
    "images_dir": "/path/to/images",
    "annotations_dir": "/path/to/annotations",
    "output_dir": "/path/to/output",
    "train_ratio": 80,
    "val_ratio": 20,
    "test_ratio": 0,
    "max_retries": 1
  }'
```

返回中获取 `task_id` 后查询进度：

```bash
curl "http://127.0.0.1:5000/api/progress/<task_id>"
```

### 4.3 SSE 进度流（推荐）

```bash
curl -N "http://127.0.0.1:5000/api/task/<task_id>/stream"
```

### 4.4 任务控制

```bash
# 暂停
curl -X POST "http://127.0.0.1:5000/api/task/<task_id>/pause"

# 恢复
curl -X POST "http://127.0.0.1:5000/api/task/<task_id>/resume"

# 终止
curl -X POST "http://127.0.0.1:5000/api/task/<task_id>/stop"
```

## 5. Python 调用模版（可直接复用）

```python
import time
import requests

BASE_URL = "http://127.0.0.1:5000"
TIMEOUT = 30

class SelfToolsClient:
    def __init__(self, base_url=BASE_URL, timeout=TIMEOUT):
        self.base_url = base_url.rstrip("/")
        self.timeout = timeout
        self.session = requests.Session()
        self.session.headers.update({"Content-Type": "application/json"})

    def _url(self, path: str) -> str:
        return f"{self.base_url}{path}"

    def _post(self, path: str, payload: dict):
        resp = self.session.post(self._url(path), json=payload, timeout=self.timeout)
        data = resp.json()
        if not resp.ok or not data.get("success", False):
            raise RuntimeError(f"POST {path} failed: {data}")
        return data

    def _get(self, path: str):
        resp = self.session.get(self._url(path), timeout=self.timeout)
        data = resp.json()
        if not resp.ok or not data.get("success", False):
            raise RuntimeError(f"GET {path} failed: {data}")
        return data

    # ---- 同步接口示例 ----
    def scan_voc_classes(self, annotations_dir: str):
        return self._post("/api/scan-voc-classes", {
            "annotations_dir": annotations_dir
        })

    # ---- 异步接口示例 ----
    def create_split_task(self, images_dir: str, annotations_dir: str, output_dir: str):
        return self._post("/api/split", {
            "format": "voc",
            "images_dir": images_dir,
            "annotations_dir": annotations_dir,
            "output_dir": output_dir,
            "train_ratio": 80,
            "val_ratio": 20,
            "test_ratio": 0,
            "max_retries": 1
        })

    def get_progress(self, task_id: str):
        return self._get(f"/api/progress/{task_id}")

    def wait_for_task(self, task_id: str, interval_sec=0.5, timeout_sec=3600):
        deadline = time.time() + timeout_sec
        while time.time() < deadline:
            data = self.get_progress(task_id)
            status = data.get("status")
            if status in {"completed", "error", "stopped", "cancelled"}:
                return data
            time.sleep(interval_sec)
        raise TimeoutError(f"task timeout: {task_id}")


if __name__ == "__main__":
    client = SelfToolsClient()

    # 1) 发起任务
    task = client.create_split_task(
        images_dir="/path/to/images",
        annotations_dir="/path/to/annotations",
        output_dir="/path/to/output"
    )
    task_id = task["task_id"]
    print("task_id:", task_id)

    # 2) 等待结果
    final = client.wait_for_task(task_id)
    print("final status:", final["status"])
    print("result:", final.get("result"))
```

## 7. 生产接入建议

1. 在网关层加鉴权（Token/API Key）  
2. 给异步任务增加业务侧幂等键（避免重复提交）  
3. 失败按 `error_code` 做可重试分类（如参数错误不重试，网络错误可重试）  
4. 对长任务优先使用 SSE，而非高频轮询
